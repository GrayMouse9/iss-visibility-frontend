# Время видимости МКС с Земли — фронтенд

ЛР5 по дисциплине «Разработка интернет-приложений», вариант 18.
Гостевое приложение для просмотра точек наблюдения МКС: две страницы,
локальные mock-данные и медиа. Внешний вид перенесён из ЛР2.

## Запуск

Проверено с Node.js 24 и npm 11.

```bash
npm ci
npm run dev
```

Открыть http://localhost:5173. Сервер Vite выводит фактический порт в терминале.
Бэкенд, Docker, PostgreSQL, Redis и MinIO для ЛР5 не нужны.

## Страницы и действия

| Адрес | Страница | Поля и действия |
|---|---|---|
| `/observation_points` | Плитка | Фото, название, широта, число отметок. Ползунок «Широта, от» (−90…90°), кнопка «Найти». Карточка открывает выбранную точку в ленте |
| `/feed` | Лента | Первая точка из mock |
| `/feed/:id` | Лента | Видео, название, описание, широта, долгота, число отметок; «Ещё/Меньше», «Далее» |

`/feed` и `/feed/:id` — одна страница с разным выбором точки, а не две разные страницы.
Корневой и неизвестные маршруты перенаправляют на `/feed`.
Неизвестный или некорректный ID показывает сообщение и ссылку «К плитке».

Нижнее меню содержит четыре пункта: «Лента», «Добавление», «Плитка», «Войти».
Доступны только «Лента» и «Плитка», текущий пункт выделен.
Счётчики отметок доступны только для просмотра, гостевой интерфейс не меняет их.

Фильтр применяется кнопкой: перемещение ползунка само по себе не меняет плитку.
Остаются точки с широтой не ниже выбранной. При отсутствии результатов выводится
«Ничего не найдено». Для сброса выбрать −90° и нажать «Найти».
После ухода с плитки фильтр сбрасывается; сохранение между страницами относится к ЛР7.

«Далее» использует порядок объектов в mock, а не `id + 1`: после ID=2 идёт ID=4.
После последней точки ID=8 открывается ID=1, как в ЛР2 и текущем API.
Вход через меню «Лента» открывает первую точку полного mock-набора.

## Данные и медиа по умолчанию

Пять точек взяты из сохранённого seed бэкенда, шестая — учебная точка Москвы
без фото и видео для демонстрации fallback. Seed при запуске фронтенда не выполняется.
Все пути медиа локальные; запросов к API и S3 нет.

При пустом или недоступном файле подставляются:

- `public/media/default-observation-point.jpg`;
- `public/media/default-observation-point.mp4`.

Если недоступно и видео по умолчанию, остаётся изображение, без повторных попыток по кругу.
Видео запускается без звука, повторяется и проигрывается внутри страницы.
Кнопок управления видео нет, как в ЛР2.
При смене точки видео и раскрытие описания сбрасываются.

Положительная широта — северная, отрицательная — южная; положительная долгота —
восточная, отрицательная — западная. `null` показывается как «Не указана».
В плитке широта округляется до двух знаков, в ленте координаты — до четырёх.

## Компоненты, props и хуки

`ObservationPointCard` и `ObservationPointVideo` получают точку через prop
`observationPoint`. Фильтр получает функцию `onApply` от страницы и вызывает её
при отправке формы. Данные идут от родителя к ребёнку, функция сообщает родителю
о действии пользователя.

- `useState`: введённая/применённая широта, состояние fallback.
- `useEffect`: проверка poster и очистка обработчика ошибки.
- `useParams`: ID точки из URL ленты.
- `useLocation`: выбор оформления ленты в общем макете.

Redux и React Context в проект не добавлялись. Раскрытие описания использует
нативные `<details>`/`<summary>`. Видео воспроизводится средствами браузера через
атрибуты `autoPlay`, `muted`, `loop` и `playsInline`.

## Проверки

```bash
npm run build
npm run lint
npx playwright install chromium
npm test
```

Playwright сам запускает отдельный Vite на порту 5175. Этот порт должен быть свободен.
При необходимости путь к уже установленному Chromium можно передать через
`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. При настроенном системном HTTP-прокси
добавить `localhost,127.0.0.1` в `NO_PROXY`/`no_proxy`.

Проверяются фильтр/пустой результат/сброс, переход по карточке, пропуски ID,
замыкание и история браузера, видео и координаты, описание, недоступные действия,
пустые и битые медиа, некорректные ID, фиксированный размер макета и отсутствие кнопок управления видео.

Материалы сдачи, РПЗ и диаграммы находятся вне репозитория в соседней папке `reports/ЛР5`.
